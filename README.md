# laser
Calculations regarding Gaussian and Non-gaussian Laser beams passing through f-theta optics

## Getting started

Requires Python 3.10+ (developed on Python 3.13).

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook Laser_Beam_Calculator.ipynb
```

Run Section 1, enter your laser parameters in Section 2, then run the section that answers your question.
